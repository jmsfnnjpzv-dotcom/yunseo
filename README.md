# 윤서의 오늘 룩 (ootw.yunseo)

정적 사이트입니다. 프레임워크 없이 HTML/CSS/JS만 사용합니다.

## 새 룩 추가하는 법
1. `img/ep003/` 폴더에 이미지 넣기 (720×960 webp, 썸네일 `1-s.webp` 480×640)
2. `data/looks/003.json` 추가 (`002.json` 복사 후 수정)

끝. 홈 목록은 `001.json`부터 번호 순서대로 자동으로 찾아 불러옵니다.

- `tags`: 카페 · 데이트 · 주말 · 산책 · 하객 · 저녁약속 · 여행 (홈 필터 칩)
- `weather`: 기온 범위와 한 줄 메모
- 아이템 링크는 에이블리 제휴 앱링크(제품별 개별 링크). 가격은 넣지 않습니다.
